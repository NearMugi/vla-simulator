# Goal
確定した仕様に基づき、実装に向けた具体的なステップバイステップの作業プラン（`.agent/tasks/plan.md`）を作成する。

# Instructions
1. `.agent/tasks/task.md` および、仕様が確定した `.agent/tasks/qa.md` を読み込むこと。
2. 作業プランのフォーマットとして、プロジェクト内の `.agent/templates/plan_template.md` を読み込むこと。（※ファイルが存在しない場合は、ユーザーにフォーマットを尋ねること）
3. 読み込んだ `.agent/tasks/task.md` と `.agent/tasks/qa.md` の内容を統合・分析し、フォーマットに従って具体的な実装ステップを立案すること。
4. 作成した作業プランを、`.agent/tasks/plan.md` として新規作成（または上書き保存）すること。
5. チャット上で「.agent/tasks/plan.mdを作成しました。この手順で実装を開始してよいか確認してください」とユーザーに伝えること。
6. ユーザーから「プランOK」「実装開始」などの承認を得るまでは、実際のコーディングを開始しないこと。
