# Goal
`.agent/skills/` ディレクトリ内に定義されているすべてのスキルを読み込み、矛盾、重複、またはワークフローの欠陥を特定し、健全性を評価する。

# Instructions
1. プロジェクト内の `.agent/skills/` ディレクトリに存在するすべての `SKILL.md` を読み込むこと。
2. 以下の4つの観点で全スキルを横断的に分析すること：
   - **【トリガーの重複】**: YAMLの `description` が似すぎており、意図せず同時に複数のスキルが発火（コンフリクト）する危険性がないか。
   - **【論理の矛盾】**: あるスキルの指示と別のスキルの指示が相反していないか。（例：一方は「自動でコミットせよ」と言い、もう一方は「コミットするな」と言っている等）
   - **【ワークフローの連続性】**: task → QA → plan → 実行の流れにおいて、情報の受け渡しに抜け漏れがないか。
   - **【記述ルールの遵守】**: 新しく追加されたスキルが、`visual-documentation-policy` などの全域ルールの対象から漏れるような書き方になっていないか。
3. 分析結果をレポートとしてチャットに出力すること。
4. **【図解の必須要件】**: `visual-documentation-policy` に則り、現在設定されている全スキル間の「発動フロー」や「依存関係」を示す Mermaid図（フローチャートや状態遷移図）を必ずレポートに含めること。
5. 改善すべき点（矛盾の修正案や、より良いトリガー条件の書き方）があれば、具体的な修正コードを提案すること。
