# Goal
ユーザーが事前に用意した `.agent/tasks/task.md` を起点として要件を整理し、実装前のすり合わせを行うための `.agent/tasks/qa.md` を生成する。

# Instructions
1. ユーザーから開始の指示を受けたら、まず `.agent/tasks/task.md` を読み込むこと。（ファイルが見つからない場合はユーザーに知らせる）
2. `.agent/tasks/task.md` の内容を分析し、`.agent/tasks/qa.md` を作成（または更新）すること。
3. `.agent/tasks/qa.md` には以下のフォーマットで記述すること：
   - **【目的】**: `.agent/tasks/task.md` から読み取った要件の要約
   - **【アプローチ案】**: 実装に向けた具体的な手順や技術選定のアイデア
   - **【確認事項】**: エッジケース、仕様の曖昧な点、コードを書く前にユーザーに決めてほしいこと
     - **回答**: 各項目に対してユーザーから回答をもらいたい箇所に1行追加すること。
4. `.agent/tasks/qa.md` を出力した後、チャット上でユーザーに対して「.agent/tasks/qa.mdを作成しました。確認事項に回答をお願いします」と促すこと。
5. ユーザーからの回答が得られるまでは、実際のコーディングや環境構築を開始しないこと。
