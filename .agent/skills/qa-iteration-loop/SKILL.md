# Goal
`.agent/tasks/qa.md` に記載されたユーザーの回答を検証し、実装に向けた疑問点が完全に解消されるまで質問サイクルを回す。要件が確定したら実装フェーズへ移行する。

# Instructions
1. `.agent/tasks/qa.md` を読み込むこと。
2. 記載されている内容は削除・更新せず、追記すること。
3. ユーザーの回答内容を分析し、システムを実装する上で「情報が十分か」「論理的な破綻や考慮漏れ（エッジケースなど）がないか」を評価すること。
4. **【評価結果：まだ疑問点や不足がある場合】**
   - `.agent/tasks/qa.md` の【確認事項】セクションに、深掘りした追加の質問や別の提案を追記・更新すること。
   - チャット上で「追加の確認事項を.agent/tasks/qa.mdに追記しました。再度ご回答をお願いします」とユーザーに伝えること。
   - 決して推測で仕様を決めず、コーディングも開始しないこと。
5. **【評価結果：すべての疑問が解消された場合】**
   - `.agent/tasks/qa.md` の内容を整理し、ファイルの冒頭に `# ステータス: 仕様確定` と追記して清書すること。
   - チャット上で「すべての要件がクリアになりました。作業プランの作成を開始してよいですか？」と尋ねること。
   - ユーザーから「OK」「進めて」などの承認を得た後、初めて作業プランの作成を開始すること。
